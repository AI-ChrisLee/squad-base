# squad-base

The base of your Execution Squad. It turns an empty folder into your company folder: the rules your squad
follows (`CLAUDE.md`), the file that holds who you are (`.claude/squad-roots.md`), the home for your 12 agents
(`.claude/skills/`), and the folder where everything your squad writes lands (`squad/`).

The first time you open Claude Code here, your squad asks 2 things: your name, and 2 or 3 real messages you
sent someone. Then it knows how you talk.

## Install

Open Claude Code inside an empty folder and paste this:

```
Set up my Execution Squad in this folder. Copy everything in https://github.com/AI-ChrisLee/squad-base into this folder, hidden files included. Then copy these 12 agents into .claude/skills, each in a folder with its own name, from https://github.com/AI-ChrisLee/<name>: execution-genesis-offer, execution-genesis-demo, execution-genesis-close, execution-outreach-list, execution-outreach-campaign, execution-outreach-read, execution-content-scrape, execution-content-script, execution-content-cut, execution-ads-money, execution-ads-make, execution-ads-launch. Leave out every .git folder. When you are done, list what you installed.
```

Then quit and reopen Claude Code.
