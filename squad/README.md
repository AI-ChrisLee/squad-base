Everything your squad writes lands here.

The warm week (g3) fills squad/warm-notes.md (every quote, verbatim),
squad/draft-offer.md (your offer, forming call by call) and squad/demos/
(one folder per person). The Winning Offer (g4) writes squad/business.md,
and every skill after it reads that file first. The Close (g5) writes
squad/clients/, squad/calls/ and squad/pipeline.md. The 90-Day Plan (g6)
writes squad/90-day-plan.md, plus squad/cold-list.md if your lane is
outreach.
