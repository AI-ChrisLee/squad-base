Everything your squad writes lands here.

squad/posts/ holds the daily post, one file a day, and the Sunday post (bip,
g3). squad/warm-script.md is your interview script (warm-script, g4).
squad/clients/ holds one folder per real person: the transcript and their
words verbatim in notes.md (warm-extract, g4); the sales skill adds each
call's brief and debrief there (g6). squad/business.md is the offer: the warm
calls draft it when someone names what they want and the next step has a
date, and The Winning Offer (g5) forges and confirms it; every skill after it
reads that file first. The Close (g6) writes squad/sales.md, squad/sales-page.md
and squad/pipeline.md. The shell lives in squad/mep/, one folder per buyer
(g7). The 90-Day Plan (g8) writes squad/90-day-plan.md.
